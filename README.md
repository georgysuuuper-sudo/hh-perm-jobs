# Вакансии недели — Пермь (от 50 000 ₽)

Статический сайт на GitHub Pages: таблица вакансий hh.ru (Пермь, зарплата
от 50 000 ₽/мес, за 7 дней) с метками шорт-листа/ловушек и таймером до
следующего парса.

- Сайт: корень репо (`index.html`, `app.js`, `style.css`), данные в `data/`
- Парсер: `parser/parse.py` — качает выдачу hh.ru, фильтрует, пишет `data/*.json`
- Обновление: GitHub Actions по cron `0 5 * * *` UTC (08:00 МСК ежедневно),
  коммитит свежие данные → Pages обновляется автоматически

## Локальный запуск парсера

```
python parser/parse.py
```

Нужен `curl` в PATH (в Windows и Ubuntu есть из коробки).
